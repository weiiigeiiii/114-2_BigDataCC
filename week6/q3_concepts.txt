Q1：chown 和 chmod 有什麼不同？請分別說明它們的功能，並各舉一個使用情境。
A1：
chown (Change Owner) 是用來修改檔案或目錄的「擁有者」或「所屬群組」。
使用情境：當網頁管理員上傳了新網頁檔案，但網頁伺服器（如 Apache/Nginx）需要存取權時，可以用 sudo chown www-data:www-data index.html 將檔案擁有者直接移交給伺服器帳號。

chmod (Change Mode) 是用來修改檔案或目錄的「存取權限」（讀、寫、執行，即 r、w、x）。
使用情境：當你寫好了一個 shell 腳本（例如 backup.sh），預設無法直接執行，可以用 chmod +x backup.sh 來賦予它執行的權限。

Q2：你和 3 位同學要合作做專題，需要在 Linux 上建立一個共用資料夾，讓組員都能讀寫檔案，但其他人不能存取。請寫出你會使用的指令（提示：需要建立群組、設定目錄的群組和權限）。
A2：

建立一個名為 project 的新群組：
sudo groupadd project

將自己和 3 位組員的帳號（假設為 user1, user2, user3）通通加入該群組：
sudo usermod -aG project zhouwenwei
sudo usermod -aG project user1
sudo usermod -aG project user2
sudo usermod -aG project user3

建立專題用的共用資料夾（假設在 /srv/project_dir）：
sudo mkdir -p /srv/project_dir

將該資料夾的所屬群組變更為 project：
sudo chgrp project /srv/project_dir

設定權限，讓擁有者和群組都能讀寫執行（rwx），而其他人完全無法存取（---）：
sudo chmod 770 /srv/project_dir

Q3：Linux 判斷權限時，是按什麼順序檢查的？假設一個檔案的權限是 rwxr-x---，擁有者是 alice，群組是 project。請回答以下三個人分別能做什麼操作：(a) alice（擁有者）能做什麼？(b) bob（屬於 project 群組）能做什麼？(c) charlie（不屬於 project 群組）能做什麼？
A3：
Linux 判斷權限的檢查順序為：
擁有者（User） -> 所屬群組（Group） -> 其他人（Others）。
系統會由左至右依序比對，一旦符合其中一個身份，就會直接套用該身份的權限，不再往下檢查。

針對該檔案（rwxr-x---）的三人權限如下：
(a) alice：符合「擁有者」身份，權限為 rwx，因此可以進行「讀取（看內容）」、「寫入（修改/刪除）」與「執行」該檔案。
(b) bob：符合「所屬群組」身份，權限為 r-x，因此可以進行「讀取（看內容）」與「執行」該檔案，但「不能修改或刪除」它。
(c) charlie：屬於「其他人」身份，權限為 ---，因此對該檔案「沒有任何權限」，無法讀取、無法修改、也無法執行。
